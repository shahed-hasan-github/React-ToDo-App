# React-ToDo-App

🌟 Overview

This is a simple yet powerful To-Do application built with React. It allows users to add, edit, delete, and mark tasks as complete, showcasing modern React development practices and state management.

🔥 Features

✅ Add & Delete Tasks – Easily manage daily to-dos
✅ Mark Tasks as Completed – Cross out finished tasks for better tracking
✅ Edit Tasks – Update task details on the go
✅ Persistent Storage – Saves tasks using Local Storage / Backend API
✅ Filter Tasks – Sort by completed or pending status
✅ Responsive Design – Works on desktop and mobile
✅ Dark Mode – Toggle between light and dark themes
